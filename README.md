# 🌐 PANEL GLOBAL DE CONTROL DE LICENCIAS (GITHUB PAGES)

Este proyecto es tu **Centro de Mando Web** para monitorear, auditar y gestionar todas las licencias de software que emitas a tus clientes (Farmacias, puntos de venta y futuros sistemas).

---

## 🚀 ¿CÓMO PUBLICARLO EN GITHUB PAGES EN 1 MINUTO?

### Opción A: Desde la Web de GitHub (Sin comandos)
1. Entra a tu cuenta en [GitHub.com](https://github.com) y haz clic en **New repository** (Nuevo repositorio).
2. Ponle un nombre, por ejemplo: `control-licencias` o `licencias-farmacia`.
3. Selecciona **Public** y haz clic en **Create repository**.
4. En la pantalla siguiente, haz clic en **"uploading an existing file"** (subir archivos existentes).
5. Arrastra los 3 archivos de esta carpeta:
   - `index.html`
   - `licenses.json`
   - `README.md`
6. Haz clic en **Commit changes** (Guardar cambios).
7. Ve a la pestaña **Settings** (Configuración del repositorio) -> en el menú de la izquierda haz clic en **Pages**.
8. En **Branch**, selecciona `main` y la carpeta `/(root)`. Haz clic en **Save**.
9. ¡LISTO! En 30 segundos GitHub te dará tu enlace web en vivo:
   `https://tu-usuario.github.io/control-licencias/`

## 🎯 CARACTERÍSTICAS DEL PANEL
- **100% Gratuito en la Nube**: Funciona en GitHub Pages sin pagar servidor ni base de datos.
- **Acceso Multi-Dispositivo**: Puedes abrirlo desde tu celular, tablet o cualquier computadora del mundo.
- **Buscador en Tiempo Real**: Filtra al instante por cliente, HWID de la máquina, estado o ciudad.
- **Exportación Automática**: Descarga `licenses.json` o la planilla en `.csv` (Excel) con un solo clic.
- **Revocación y Control**: Puedes activar, pausar o revocar licencias directamente desde la interfaz.
- **Modo Oscuro / Pro**: Diseño premium con Tailwind CSS y FontAwesome.
