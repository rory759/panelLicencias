¿Cómo obtener tu Token de GitHub en 1 minuto?
  1. Entra en GitHub a Settings → Developer Settings → Personal access tokens (Tokens classic).
  2. Haz clic en Generate new token, ponle un nombre (ej: Panel Licencias) y marca la casilla repo.
  3. Copia el token generado (ghp_...) y pégalo abajo.
